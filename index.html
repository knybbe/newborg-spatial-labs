Newborg Spatial Labs

Capture, stream and explore reality

Early previews from Newborg Spatial Labs: Gaussian splat viewing, Potree 2 point clouds, real-time photogrammetry, and one-photo-to-splat generation. All built with permissively licensed open source.

Gaussian Splat Viewer

Preview

Godot-based viewer for single .ply / .splat / .spz files and OGC 3D Tiles splat streaming. Runs on web, Android, Windows, Mac and iOS.

Potree 2 Viewer

Preview

Rust + WebGPU point cloud viewer with progressive in-browser indexing. Tauri v2 shell for all platforms; points appear immediately while the index builds.

WebGPU Rust Tauri v2

Real-time Photogrammetry

Preview

Rust → WebAssembly + WebGPU that turns a phone camera into a live point cloud. Android Chrome first (Galaxy S26 Ultra), with AR depth when available.

WASM WebGPU Phone browser
Open app Site

Photo to Splat

Preview

One photo of an object becomes a 3D Gaussian splat (.ply). Runs on knyai’s GPU over Tailscale, with the Speridlabs Idol Hugging Face Space as fallback. Phone, tablet and laptop.
